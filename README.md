# Стежок — редактор схемы вышивки

Автономная статическая версия редактора. Все изменения схемы сохраняются в браузере пользователя; проект также можно скачать в JSON и загрузить обратно.

## Google Drive

Редактор умеет хранить одну приватную копию проекта в скрытой папке данных приложения Google Drive. Используется узкий OAuth scope `drive.appdata`: другие файлы пользователя редактор не видит.

Для подключения:

1. В Google Cloud включите Google Drive API.
2. Создайте OAuth Client ID типа **Web application**.
3. Добавьте разрешённый JavaScript origin `https://inclement1a.github.io`.
4. Вставьте Client ID в окне **Облако** на сайте.

Client ID можно также передать при сборке через публичную переменную `NEXT_PUBLIC_GOOGLE_CLIENT_ID`. Токен доступа сохраняется только в памяти вкладки и после истечения срока действия запрашивается повторно.

## Публикация

Репозиторий настроен на автоматическую публикацию в GitHub Pages. После каждого изменения в ветке `main` GitHub Actions собирает проект и обновляет сайт.

В настройках репозитория откройте **Settings → Pages** и выберите **GitHub Actions** в качестве источника публикации.
